# ReactionMark

The four reaction types as fixed shapes with a word: burst = Panic, triangle = Credible concern, star = Wonder, rising sun = Optimism.

**The consumer provides** a reaction id (`panic`, `concern`, `wonder`, `hope`).

- The shape and word are the meaning; the fill (`react-*`) is reinforcement and changes per era. Never show a colour dot without the shape and label.
- Mark 20px beside `label` text in `ink`. On filter chips and the legend, the same mark at 16px.
- New reactions (cooperation, denial, …) get a new, clearly different silhouette before they get a colour.
